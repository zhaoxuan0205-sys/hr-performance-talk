# 谈绩效｜直接管理者的绩效反馈面谈准备工具

**在线使用：<https://zhaoxuan0205-sys.github.io/hr-performance-talk/>**

说清情况，带走一份面谈方案。逐人准备，谈完一次导出所有人的沟通方案。

## 特点

- **无需登录注册**：打开即用；
- **数据只存在你自己的浏览器里**（localStorage），不上传服务器，关闭再打开还在；
- **分析在本地运行**：从你写的文字里抽取"可直接陈述的事实 / 先不要下的结论 / 面谈要核实的问题 / 管理者责任 / 行动约定"，不联网、无调用成本；
- **高风险分流**：识别辞退、降薪、歧视、骚扰、工伤、劳动争议等情形时，停止输出话术，建议转 HR/法务；
- 不打分、不排名、不判断是否胜任、不生成处分建议；
- 支持语音输入（浏览器转文字，不上传录音）、逐人方案历史版本、整批 Markdown 汇总导出、JSON 备份/导入。

## 使用建议

1. 首次打开点「载入一个示例看看」了解流程；
2. 数据在本机浏览器中，**换设备或清理浏览器数据会丢失**——定期在「设置」里导出 JSON 备份；
3. 涉及劳动关系处置的材料属于敏感信息，建议用个人设备使用，不要在公用电脑上保存。

## 开发

- `src/` 为源码（原生 JS，无构建、无依赖）；
- `node build.js` 可将 `src/` 打包为单文件 `index.html`（也可直接分发该单文件离线使用）；
- 修改后运行 `node build.js` 重新生成并推送即可更新线上版本。
